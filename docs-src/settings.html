Settings

Open the frame's page and scroll to Settings. Press Save at the bottom to keep changes. They are stored on the memory card.

Wi-Fi

Nearby Wi-Fi networks, Wi-Fi network, Wi-Fi password
Pick your home network from the list (Rescan looks again) and type its password. Leave the name blank to use only the frame's own hotspot. Changing these turns Save into Save & connect, which restarts the frame onto the new network. Joining uses 2.4 GHz networks.
Access point name and password
The frame's own hotspot, used for first-time setup and as the fallback when your Wi-Fi isn't reachable. The password must be 8 or more characters. Leave it blank for an open hotspot.
Hostname
The frame's name on your network: http://name.local. Changing it changes the address.

How the frame hangs

Landscape (wide), or portrait turned right or left. See Adding photos. Panel mounted upside down is on for the frame as it ships; change it only if you've remounted the panel.

Status screen

A large clock and four cards. It appears when you press KEY, and optionally at the top of every hour.

Typeface
Clean, Warm, Dramatic, Classic, Friendly, Modern or Technical.
Show it
Only when I press KEY, at the top of every hour, or every half hour.
For (minutes)
How long it stays up before the photo comes back.
Short press of KEY
Wake the frame and show the status screen, or only wake the frame.
Cards 1 to 4
Choose what each card shows, or tap a ready-made set: Home (indoor, battery, photos, sunset), Nature (indoor, sunset, moon, daylight) or Technical (battery, photos, Wi-Fi, next photo). Show it on the frame now previews your choice.

The cards:

  • Indoor: temperature, humidity and a tag (DRY, NORMAL, ELEVATED, or HIGH with a mould-risk warning), plus a "feels like" when it's warm.
  • Battery, Photos (count and card space), Wi-Fi (name and signal), Next photo.
  • Sunrise / sunset, Moon (phase) and Daylight (hours today). These need your location: a ZIP code, coordinates, or an automatic lookup.

Time and place

Hush mode
The frame never connects to the internet. The page sets its clock whenever you open it. Details.
Set the time, time zone and location automatically
Off while Hush is on. Otherwise the frame asks a time server and a lookup service. Details.
ZIP code, latitude and longitude
For the sun and moon cards. A US ZIP code fills in coordinates on your own device, without any lookup. Outside the US, enter latitude and longitude directly.
Temperature
°F with a 12-hour clock, or °C with a 24-hour clock.
Time zone
Your browser's zone is offered. It's locked when the frame sets it automatically.
Run first-time setup again
Reopens the wizard from your first visit.

Schedule

Change photo every (minutes)
0 means never; use Next photo or the BOOT button. The default is 60.
Change photos at these times instead
For example 07:00, 19:00. When set, this replaces the interval.
Quiet hours
No photo changes and no status screens between the two times, such as 23:00 to 07:00.
Photo order
In order follows the order you added them. Shuffle picks a random photo each time, so the same one can come round again soon (with 660 photos you'd expect about four repeats in three days). Advanced shuffle shows every photo as often as every other and spreads them out evenly: a photo only comes back about a round later, and new photos are shown first. The frame keeps a small note of what it has shown on the memory card.
Sleep after inactivity (minutes)
How long the frame stays awake (red light on) for the page after you stop using it. 0 means never sleep, which drains the battery.
Internet time server
Optional. Used only when Hush is off.

Firmware

Shows the running version and lets you install an update. See Updating.
