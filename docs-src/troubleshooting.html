Troubleshooting

Find what you're seeing. Most things come down to the frame being asleep, the wrong Wi-Fi, or the card.

The screen is blank

A redraw takes about 20 seconds, so give it that. Then check the red light: if it's off, the frame is asleep, so press KEY. If there's still nothing, check the memory card is pushed in all the way, and that the frame has power (try a different USB cable and charger).

I can't see the frame's Wi-Fi

Hold KEY for 2 seconds. The screen shows the name the frame is using. The frame's own hotspot is on the 2.4 GHz band, which every phone can join. Its name looks like Halcyon-C121, and the screen shows the password. If you don't see it, the frame has joined your home Wi-Fi instead: use the address on the screen.

My phone says the Wi-Fi has no internet

That's expected: the frame's hotspot doesn't give internet access. When your phone asks whether to stay connected, stay connected. On some phones it also helps to turn off mobile data while you set up.

The page won't open

  • Is the frame awake? Press KEY and wait ten seconds.
  • Are you on the same Wi-Fi as the frame (or on its hotspot)?
  • Try the numeric address from the screen (like 192.168.1.37) instead of the .local name. Some Android phones can't use .local names.
  • Hold KEY for 2 seconds to show the address again.

The frame says "Wi-Fi problem"

It couldn't join your network. The screen says whether the password seems wrong or the network wasn't found. Join the frame's own hotspot as shown, open its page, and fix the details in Settings (pick your network from the list again). It only uses 2.4 GHz networks, so a "5 GHz only" network won't work.

Photos aren't changing

  • Check Settings → Change photo every. 0 means never, and a set of times replaces the interval.
  • Check Quiet hours.
  • Are the photos cut for the way the frame hangs? The slideshow skips photos made for the other orientation, and the page marks them.
  • The frame changes photos while asleep, on a timer. Pressing BOOT shows the next one now.

The status screen doesn't show

Check Settings → Status screen → Show it. "Only when I press KEY" means it never appears by itself.

The sun and moon cards ask for a setting

They need a location. Enter a ZIP code, or latitude and longitude, in Settings, or switch off Hush and use the automatic lookup.

The time is wrong

Open the frame's page: it sets the clock from your phone. Then check the time zone in Settings. In Hush mode, do this now and then.

Photos look blotchy or dull

The panel has six inks: black, white, red, yellow, green and blue. Everything else is built from dots of those, so fine texture and soft gradients look different from a screen. In the editor, try lowering the dithering strength for smoother areas, raising colour strength, or choosing Fill or Whole photo to change the crop. The preview is what the frame will show.

"No memory card" or "Can't read the card"

Push the card all the way in, then press KEY. If it still can't read it, format it as FAT32 on a computer (this erases everything on it). Your photos live only on the card.

The battery

Each redraw uses a lot of power for 20 seconds, so what drains the battery is how often the picture changes. Change photos less often, or turn the status screen off, for longer battery life. Battery life hasn't been measured yet, so these guides don't promise a number. When it's nearly empty, the frame shows Please charge me.

An update didn't work

Use a wall charger or a good USB port, then try again. Nothing is lost when an update fails: the old version keeps running. See Updating.

Starting over

To go back to the factory firmware, or to reinstall Halcyon Frame (including a frame that won't start), see Going back to the factory firmware and the installer on the home page. The installer can also rescue a frame whose firmware won't start: put it in download mode (hold BOOT, tap PWR) first.

Still stuck

Open an issue and say what the screen shows. Include the firmware version, which is on the start screen and at the bottom of the frame's page.
