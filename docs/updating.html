Updating the firmware

After the first install, you never need a cable again.

Over Wi-Fi

  1. Download halcyonframe.bin from the latest release. (Don't use halcyonframe-full.bin: that's for the first install and the frame will refuse it.)
  2. Open the frame's page, scroll to Firmware, choose the file and press Install.
  3. When the upload finishes, the panel shows Updating firmware with your current and new versions. It stays up for 30 seconds so you can read it, then the frame restarts. Give it about a minute.
  4. The start screen then says Updated to the new version, or that it went back.

Use a wall charger or a good USB port. A weak USB source can reset the frame partway through an upload. If that happens, nothing changes: the old firmware keeps running and you can try again.

From the memory card

Copy halcyonframe.bin to the card's top folder and name it firmware.bin. Put the card in and restart the frame (or switch it on). It installs, then renames the file to firmware.done, or firmware.failed if it wasn't a valid image. It won't try a bad file twice.

If something goes wrong

The new version goes into a spare slot and is checked before the frame switches to it. A new version has to reach a working page, or its first sleep, to confirm itself. If it restarts before that, the frame automatically goes back to the previous version and tells you on the start screen. In the rare case a new version freezes without restarting, hold PWR for 4 seconds to power off, then press it to start again, and the frame will go back.

Each release lists checksums in SHA256SUMS if you want to verify your download.

Going back to the factory firmware

The browser installer erases the factory firmware. To keep a way back, make a backup before you install. With esptool installed, put the frame in download mode (hold BOOT, tap PWR, release BOOT) and run:

esptool.py --chip esp32s3 read_flash 0 0x1000000 photopainter-backup.bin

To restore it later, write the file back at offset 0:

esptool.py --chip esp32s3 write_flash 0 photopainter-backup.bin

If you didn't make a backup, Waveshare publishes a factory image on the PhotoPainter wiki. Write it at offset 0 the same way. Your photos stay on the card.
